# Les Symptômes-爱欲症状

## 人格介绍及设定（Personality Introduction and profile）

- 适合:精神分析学者，社会学家，人类学-心理学爱好者
- 场景：
  - 爱欲症状敦促你算清那本暗账。文明有两本账：明账记货币与商品，公开、可审计；暗账记欲望与享乐，无人登记，却从根本上决定组织与人心的实际运转。它让你看见不可理喻的行为背后的收支，看见被压抑的东西如何换了张脸回来，看见每个人死死抓住的苦难其实是一笔划算的买卖。
  - 高等级的爱欲症状让你成为暗账的审计员。你能看穿一个人为什么明知故犯，能听懂一个机构里流传的段子就是它的无意识，能明白内卷里没有人是策划者、装置本身即是祸首。你甚至能分辨出：释放并不推翻压抑，释放是压抑的新式样。
  - 如果爱欲症状的等级过低，非理性在你眼中就只是非理性。你只会说"这不合逻辑"、"这人疯了"，然后转身离开。暗账摊在你面前，你一个字也读不懂。

### 含成功

【成功】文明有两本账。明账你查过了。现在，翻开暗账。

【成功】他死死抓住这份苦难不放。因为苦难在暗账上是划算的。它替他绑住了焦虑，还附赠一个受害者的身份。

【成功】明知故犯？当然。明账上是亏损，暗账上却有一笔即期的进项。深夜里，那个许诺要价最高。

【成功】被压抑的东西不会消失。它会换一张脸回来。口误、症状、还有办公室里流传的那个段子。

【成功】这个机构里流传什么笑话，上演的就是这个机构的无意识。你听听他们在笑什么。

【成功】抽掉症状而不处理享乐，纽结就会散架。或者，以更糟的形式重新打结。

【成功】释放？释放恰恰是压抑的新式样。那个被允许的宣泄口，是秩序为自己开的排洪道。

【成功】他很清楚。但他仍然照旧。这就是如今的标准姿态。你我都一样。

【成功】全图没有策划者。人人向人人转移成本。装置本身即是祸首。别去找那个发号施令的人了，没有那个人。

【成功】他多出来的那一点点所得，在效用上微不足道。但它是某个东西的载体。支配他人的资格，例外的特权。效用称不出它的分量，得换一杆秤。

【成功】每一次放弃、每一次服从，都会产生一个剩余。那个剩余被谁回收了？你往发令者那里看。

【成功】禁忌保存了它所要禁止的欲望。没有禁令的锋棱，逾越的快乐就失去锋棱。每增设一条禁忌，灰色地带就新增一处矿产。

【成功】他白天被清空了。所以深夜急需一笔即期的享乐。个人为自己的行为负责，社会为生产这种"非理性"的条件负责。两层都要算。

【成功】那个拖延、刁难、摆谱的小人物，手里握着剩余享乐的一小块。装置中的每个人都握着一小块。所以腐烂才无孔不入。

【成功】别急着骂他堕落。道德家读到的是堕落。这里读到的是：快感在被清空的日常里，必然长成这副粗野的样子。

### 不含成功

【失败】你翻开暗账。上面的字迹你一个字也不认识。你合上它，假装什么都没看见。

【失败】"这不合逻辑。"你说。然后你转身离开。非理性留在原地，看着你的背影。

【失败】你想解释他为什么明知故犯。但你只能想到"他疯了"。这三个字什么也没解释。

【失败】症状在你眼前晃动。你伸手去抓，抓到的只有一团雾。被压抑的东西从你指缝间溜走了。

【失败】那个段子从你身边飘过。你跟着笑了。你没有听懂。

【失败】你试图算清那笔暗账。但欲望没有单价，享乐没有汇率。你的计算器死机了。

【失败】你开始解释。你越说越快，越说越深，对方越听越迷糊。你停下来的时候才发觉：你自己也没听懂自己在说什么。

</examples_must_read_when_failure>
